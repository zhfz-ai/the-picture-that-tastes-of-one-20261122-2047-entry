One ingredient only — mozzarella — drawn entirely in code: two golden sourdough halves, glossy stretched strands with white highlights, melting drips, steam wisps, warm radial light and crumbs, on a dark vignetted background. No binary assets; the program renders the picture itself at runtime.

## Run it

```sh
python3 main.py
```

Writes a deterministic 1024x1024 PNG to `/output/entry.png` (stdlib only, no network, seed fixed).
